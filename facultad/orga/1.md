# Sistemas numéricos 

## Posicionales vs No posicionales
Los no posicionales pueden ser la numeración en hebreo y el conteo romano.

En los posicionales el valor que el dígito esté aportando varía según su posición. Es diferente el `1` en el 1000 que en 10. Un ejemplo podría ser el decimal.

En el conteo decimal tenemos base, donde la base indica la cantidad de símbolos. La notación es `sumatoria de S.b^p`, donde `S` es el símbolo, `b` es la base y `p` es la posición. Esta fórmula nos permite saber el valor de cualquier número de cualquier base.

Por ejemplo, para 565:
```
sumatoria de 0 a n de S.b^pos = 5x10^2 + 6x10^1 + 5x10^0 = 565 xd
```

## Binario
De base 2.

Por ejemplo, 101101 sub2:
```
1x2^5 + 0x2^4 + 1x2^3 + 1x2^2 + 0x2^1 + 1x2^0 = 45 sub10
```

## Base hexadecimal
Base 16, donde para el 10, 11, ..., 16 se agregan A, B, ..., F.

Por ejemplo, FE0:
```
Fx16^2 + Fx16^1 + 0x16^0 = 15x16^2 + 14x16^1 + 0 = una banda
```

## Pase de decimal a otra base
Tenés que dividir el número por la base, y vas formando el número de izquierda a derecha con los restos de cada división.

Por ejemplo, 30sub10 a base 8:
```
30/8 = 3 3%8 = 3
30%8 = 6

-> Número: 36
```

Otro puede ser 50sub10 a base 7:
```
50/7 = 7 resto 1 -> 7/7 = 1 resto 0

Entonces combinamos 1 (del primer resto) 0 (del segundo resto) 1 (del último agregado) = 101
```
