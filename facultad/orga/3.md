# Comunicación con la computadora
Para identificar números negativos de los positivos en lenguaje máquina, el primer dígito se representa como un 0 en caso de positivo, y si el primer dígito es un 1 entonces es negativo.

Esto NO es el número, sino una representación. Por ejemplo:
```
101110 -> -
010111 -> +
111010 -> -
011110 -> +
```
Nótese que, en binario, estos 4 ejemplos serían positivos, ya que no tienen el signo al frente.

Para saber si un patrón de unos y ceros se trata de un número en binario o una representación, se debe de preguntar.

### Pasaje de números negativos de cualquier base
Si tenemos un número negativo (de cualquier base) y queremos pasar a otra base, en binario lo pasamos a negativo (la representación), después hacemos el complemento a la base y le sumamos 1.

Si queremos encontrar el valor absoluto de un número binario negativo que fue complementado a la base, tenes que invertir sus dígitos y sumarle 1.

Por ejemplo:
```
10110 -> 01001 + 1 = 01010 = CB = -10
1110 -> 0001 + 1 = -2
-32 base 4 -> -1110 (Paso a base 2) -> 01110 (positivo) -> 10001 + 1 = 10010 (representado) = -14
```
Todo esto es una conveción, no debemos de razonar nuestros propios procedimientos sino seguir la convención planteada.

### Overflow
En caso de que por ejemplo sumemos 2 números negativos y nos de uno positivo (y viceversa), significa que hay overflow, lo que nos indica que el número que queremos representar no entra en los dígitos iniciales.

El overflow ocurre cuando el resultado de una operación aritmética requiere más bits de los que el sistema tiene asignados para representarlo, provocando un resultado matemáticamente incorrecto.

En este caso, el carry se ignora y deja el resultado en la cantidad de bits que se puede almacenar el número. 

> Carry: es el número resultante de la suma de números cuando hay un "extra", como pasa en binario 1 + 1 = 100, donde el "1" adicional es el carry.


### Representaciones más simples de bits
Para no tener que escribir un número en bits como 0000000000000000001, preferible escribirlos (para lectura humana) en base hexadecimal, porque existe una correspondencia exacta directa de 4 a 1 (cada dígito en base 16 son 4 bits). De aquí el prefijo `0x` de números hexadecimales `0x001`.

## Flags de estado NZCVP
N = Negativo
Z = Si es cero
C = Carry 
V = Overflow
P = Bit de control que indica paridad del número (cantidad de unos pares/impares)

Ejemplo:
```
011010 + 010011 = 101101
- N = 1 (es negativo)
- Z = 0 (no es 0)
- C = 0 (no hay carry)
- V = 0 (no hay overflow)
- P = 1 (porque hay cantidad par de unos)
```
