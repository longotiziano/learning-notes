# Go

### 'Hola mundo!' en Go
```go
package main // conj de archivos .go
import "fmt" // conj de paquetes

func main() {
    fmt.Println("Hola mundo!")
}
```

### Como correrlo
```bash
# correr
# esto implica crear un .mod que tiene por ejemplo 
# información de la versión, nombre del módulo...
go mod init <modulo> # una única vez por módulo

# ir al directorio padre
cd ..

# en el directorio padre
go work init
go work use <modulo>

# volver al directorio del archivo .go
go build -o <ejecutable>
./<ejecutable>
go run <hola_mundo.go>
```

### Otras herrameintas
```bash
go fmt
go test <path>
go help
```

### Definiciones
- Paquete: conjunto de archivos .go
- Módulo: conjunto de paquetes
- Workspace: conjunto de módulos (opcional)

## Tipos de datos
Go es fuertemente tipado y de tipado estático.

### Enteros
int(8, 16, 32, 64) -> negativos y positivos; uint(...) -> positivos

### Compuestos
arrays, structs, slices, pointers, functions 

## Convenciones de importación
En caso de que la función o cualquier variable comience con mayúscula, es importable. Caso contrario no se podrá utilizar fuera del paquete.

## Convenciones de la cátedra
Nombres, funciones, variables y cualquier otra cosa se utiliza CamelCase, pero para constantes se utiliza SNAKE_CASE.

## Punteros, arreglos
Se utilizan igual que en C.
